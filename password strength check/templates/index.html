      Security education

      Essential password habits

      Use long passwords

      Length matters more than complexity alone. Aim for 16+ characters.

      Never reuse

      Unique passwords reduce the blast radius of a single breach.

      Enable MFA

      Multi-factor authentication adds a strong backup layer.

      Use a password manager

      Store and generate credentials safely instead of remembering everything.

      Avoid personal info

      Names, birthdays, and pet names are easy to guess.

      Rotate regularly

      Update critical credentials if you suspect exposure.

      FAQ

      Common questions

      What makes a password strong?

      Length, unpredictability, and diversity of characters all increase strength.

      What is entropy?

      Entropy measures how hard a password is to guess based on possible combinations.

      Why avoid dictionary words?

      Dictionary words are easier for attackers to guess with wordlist attacks.

      Why use symbols?

      Symbols expand the character set and raise the search space dramatically.

      Should I use password managers?

      Yes. Password managers make secure, unique credentials practical for everyday use.
