# 🔐 PassGuard

PassGuard is a simple web application that helps users check the strength of their passwords. It analyses a password in real time and provides feedback to help users create stronger and more secure passwords.

This project was developed to improve awareness of password security using a clean and easy-to-use interface.

## Features

- Real-time password strength checking
- Strength indicator (Weak, Medium, Strong)
- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers and special characters
- Show/Hide password option
- Suggestions to create stronger passwords
- Responsive design for desktop and mobile devices
